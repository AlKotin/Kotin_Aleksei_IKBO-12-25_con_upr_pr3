# Ассемблер и интерпретатор УВМ — вариант 9

Практическая работа № 3. На первом этапе ассемблер читает программу
на YAML и переводит её в список команд с полями A и B.

## Язык программ

Программа — непустой YAML-список. Каждый элемент содержит ровно одну
команду:

- `LOAD_CONST: число` — загрузка константы; A = 58, B = число.
- `READ:` — чтение из памяти; A = 37.
- `WRITE:` — запись в память; A = 56.
- `BITREVERSE:` — операция над битами; A = 14.

Поле B команды `LOAD_CONST` занимает 30 бит и принимает значения
от 0 до 1073741823. Остальные команды не имеют поля B.

Пример программы находится в `examples/spec.yaml`.

## Запуск

Требуются Python 3.9 или новее и библиотека PyYAML. Установка:

    python3 -m pip install -r requirements.txt

Тестовый запуск:

    ./run.sh --source examples/spec.yaml --output result.bin --test

Параметры:

- `--source` — путь к исходной YAML-программе.
- `--output` — путь к будущему двоичному файлу.
- `--test` — вывести внутреннее представление команд.

На первом этапе путь `--output` принимается, но двоичный файл ещё
не создаётся. Запись байтов предусмотрена вторым этапом.

Ожидаемый тестовый вывод:

    1. LOAD_CONST: A=58, B=684
    2. READ: A=37
    3. WRITE: A=56
    4. BITREVERSE: A=14

## Устройство программы

`src.assembler.Instruction` хранит поля команды.
`parse_instruction` проверяет одну команду.
`parse_program` разбирает YAML-список.
`read_program` читает исходный файл.
`src.main.main` обрабатывает параметры и выводит результат.

## Проверка

Сборка на первом этапе не требуется. Запуск тестов:

    python3 -m unittest discover -s tests -v

Двоичные файлы, окружение Python и служебные файлы в Git не добавляются.
