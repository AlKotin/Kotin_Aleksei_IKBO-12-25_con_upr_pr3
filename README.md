# Ассемблер и интерпретатор УВМ — вариант 9

Практическая работа № 3. Ассемблер читает программу на YAML,
преобразует её в команды УВМ и записывает машинный код в двоичный файл.
Интерпретатор будет добавлен на следующих этапах.

## Язык программ

Программа — непустой YAML-список. Каждый элемент содержит одну команду:

- `LOAD_CONST: число` — загрузка константы; A = 58, B = число.
- `READ:` — чтение из памяти; A = 37.
- `WRITE:` — запись в память; A = 56.
- `BITREVERSE:` — операция над битами; A = 14.

Поле B занимает 30 бит. Допустимые константы: от 0 до 1073741823.
Остальные команды не имеют поля B.

Пример всех команд находится в `examples/spec.yaml`.

## Машинный код

Каждая команда занимает 5 байт. Поле A находится в битах 0–5.
Поле B команды `LOAD_CONST` находится в битах 6–35.
Байты записываются начиная с младшего.

Для `LOAD_CONST: 684` результат — `3A AB 00 00 00`.
Для остальных команд результат — их код и четыре нулевых байта.

## Установка и запуск

Требуются Python 3.9 или новее и PyYAML. Установка зависимостей:

    python3 -m pip install -r requirements.txt

Пример запуска с выводом байтов:

    ./run.sh --source examples/spec.yaml \
      --output /tmp/uvm-spec.bin --test

Параметры:

- `--source` — путь к исходному YAML-файлу.
- `--output` — путь к создаваемому двоичному файлу.
- `--test` — показать байты каждой команды в терминале.

Ожидаемый вывод:

    Assembled instructions: 4
    LOAD_CONST: 0x3A, 0xAB, 0x00, 0x00, 0x00
    READ: 0x25, 0x00, 0x00, 0x00, 0x00
    WRITE: 0x38, 0x00, 0x00, 0x00, 0x00
    BITREVERSE: 0x0E, 0x00, 0x00, 0x00, 0x00

## Устройство программы

`src.assembler.Instruction` хранит команду и её поля.
`parse_instruction` проверяет одну YAML-команду.
`parse_program` преобразует YAML в список команд.
`read_program` читает исходный файл.

`src.encoder.encode_instruction` кодирует одну команду.
`encode_program` собирает полный двоичный код.
`save_program` записывает его в файл.
`format_bytes` готовит вывод байтов для тестового режима.
`src.main.main` обрабатывает параметры и запускает ассемблирование.
